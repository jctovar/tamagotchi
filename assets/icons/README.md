# Iconos Pixel para UI

## Especificaciones:
- **Tamaño**: 16x16 píxeles
- **Formato**: PNG con transparencia
- **Contorno**: #2C2424 (negro rojizo) de 1 píxel

## Iconos necesarios:

### Acciones:
- **feed.png** - Icono para alimentar
- **play.png** - Icono para jugar
- **clean.png** - Icono para limpiar
- **rest.png** - Icono para descansar

### Métricas:
- **hunger.png** - Icono de hambre
- **happiness.png** - Icono de felicidad
- **energy.png** - Icono de energía
- **health.png** - Icono de salud

## Creación de iconos:

Usa un editor de pixel art como:
- Aseprite (recomendado)
- Piskel (online gratuito)
- GIMP con escala píxel

Los iconos deben ser simples y reconocibles a 16x16 píxeles.
