# Assets Pixel-Art para Tamagotchi

## Sprites de Mascota (32x32 píxeles)

### Formato de nombres:
`{etapa}_{variante}.png`

- **etapas**: egg, baby, child, teen, adult
- **variantes**: normal, excellent, neglected

### Ejemplos:
- egg_normal.png
- baby_excellent.png
- child_neglected.png
- adult_normal.png

### Paleta de colores recomendada:
- Fondo: Transparente (PNG con alpha channel)
- Contorno: #2C2424 (negro rojizo)
- Cuerpo (normal): #FFF9C4 (crema)
- Cuerpo (excellent): #8BC34A (verde)
- Cuerpo (neglected): #95A5A6 (gris)

### Herramientas recomendadas:
- **Aseprite** - Editor de pixel art profesional (ASE, Tiled, etc.)
- **Piskel** - Editor online gratuito (https://www.piskelapp.com/)
- **GIMP** - Editor de imágenes gratuito (con escala píxel)
- **Photoshop** - Escalar imagen con "Nearest Neighbor"
